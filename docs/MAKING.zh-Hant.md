# 做一部你城市的片

[English](MAKING.md) · 繁體中文 · [简体中文](MAKING.zh-Hans.md)

這份教學帶你從零開始，用《一城春秋》的技能做出一部城市影片。做片的是 Claude Code（程式代理），你負責定故事、在瀏覽器裡看片；規則寫在 [`AGENTS.md`](../AGENTS.md) 和它指向的各步驟說明（`docs/`），代理會照它做。

## 1. 先看一部

先在[入口頁](https://cities.go5.si/xianyang/)看咸陽那部，知道成品長什麼樣：白色模型、一個時代一種顏色、連貫的旁白、每條史實都有出處。

## 2. 準備電腦

| 需要 | 用途 |
|---|---|
| [Claude Code](https://claude.com/claude-code) | 做片的代理 |
| Node 20 以上 | 播放器、渲染工具 |
| [uv](https://docs.astral.sh/uv/) | Python 環境（它會自己下載 Python 3.12） |
| ffmpeg、exiftool | 影片合成、清除元數據 |
| Chrome 和一張顯示卡 | 渲染畫面（沒有顯示卡也能跑，但慢很多） |

硬碟：每座城大約 5 GB 工作空間（下載的地圖與建築資料、渲染中的影格和音軌）。如果要在本機生成配樂，模型另外約 6 GB。

時間參考（咸陽，12 分 30 秒的片，2019 年的桌機）：編譯一次約 3 分鐘，整片渲染約 36 分鐘，混音約 2 分鐘。研究和逐段修改花的時間最多，通常要幾天。

## 3. 安裝

```sh
npx skills add alexliyu7352/city-through-time-skill -g -y
```

在終端機裡執行：它會替這台電腦上找得到的每個代理（Claude Code、Codex、Cursor、Gemini CLI 等）都裝上，也裝進共用的 `~/.agents/skills`。在某個代理裡面執行的話，只會裝給那一個代理。

這只裝技能本身（[city-through-time-skill](https://github.com/alexliyu7352/city-through-time-skill)），這台電腦上讀得懂技能的代理都能用。在 Claude Code 裡也可以用外掛裝：`/plugin marketplace add alexliyu7352/city-through-time-skill`，再 `/plugin install city-through-time@city-through-time`。這個倉庫不用你自己 clone，代理第一次使用時會做。

## 4. 第一次使用

跟代理說：「用一城春秋做〇〇，從〇〇時代開始」。第一次它會先問你工作區（就是這個倉庫：程式、規則和已做好的城市；約 300 MB，每座城另需約 5 GB）放在哪裡，clone 過去，再做「第一次使用」這一步：

- 問你這台電腦的資料放在哪裡，寫進 `local/config.json`（不進 git）。建議全部放在工作區的 `local/` 下；硬碟不夠時，也可以把大檔放到別顆硬碟。
- 檢查工具裝了沒有，用 `npm ci` 和 `uv sync` 裝好環境。

## 5. 做片的流程

代理會照下面的順序做。故事大綱、細綱、旁白稿、比例靜幀、預覽裡的片子、配樂和成片會停下來等你點頭；中間的步驟（歷代城市、鏡頭、節奏）由它自己對照範例片把關，像觀眾一樣看過再交。要改程式或換做法時，它會先說明原因和做法，你同意才動手；你點名的問題，它只改那幾處，同類的問題它會自己找出來列給你看：

1. **研究**：年代表、每條史實的出處和原文（`FACTS.md`），選出這座城的轉折點。
2. **資料**：劃定範圍（約 20–30 公里見方），抓 OpenStreetMap、建築、地形、衛星影像，先渲染一張白模給你看比例。
3. **歷代城市**：照考古報告和史料生成各時代的城，畫面上標「示意」。
4. **文案與時間軸**：先寫一條連貫的旁白，再讓畫面跟著句子走。
5. **預覽**：`node tools/preview.mjs <城市>` 起本機伺服器，在 Chrome 打開它印出的網址就能播放；代理每做完一大段（約三分之一部或整部）給你看，有問題直接跟代理說。
6. **旁白、配樂與音效**：代理會先問你用哪種方式：自己錄、線上服務（例如 MiniMax）、本機模型（例如 Stable Audio 3）、CC 曲庫，或是程式寫的配樂（不用模型、離線、免費，當作備用）。選定的方式和它的使用條款（能不能公開、能不能商用）會寫進城市的 `VOICE.md`、`MUSIC.md`。音效（光柱落地、焚城、熄燈這些時刻）可以挑，也可以不用；三樣都能在預覽裡聽。
7. **成片**：你在預覽裡點頭後才渲染：`node tools/build.mjs <城市>`。它會跑完所有檢查，交出 `dist/` 裡的影片、雙語字幕、封面和簡介。

## 6. 幾個要守的原則

- **每一條史實都要有出處**，寫在 `FACTS.md`；找不到的寧可不說。
- **示意就標示意、估算就標估算**：歷代城市是示意模型，建築年份是衛星估算。
- **只用可以公開的素材**：CC 授權或公有領域的圖片與實拍，作者和授權寫進 `CREDITS`。
- **AI 生成的要說清楚**：旁白、配樂、想像圖都在畫面和片尾標註。

## 7. 做好之後

想把它加到入口頁，照 [`CONTRIBUTING.zh-Hant.md`](../CONTRIBUTING.zh-Hant.md) 做：上傳影片、（可選）放網頁播放包、開 pull request。想給它一個自己的網站，有免費的 Cloudflare 帳號就行：`node tools/deploy.mjs --city <城市>` 把你的城市發布到 `https://<城市>.pages.dev/`，只有這座城，不帶入口頁和別的城市（同一份文件第 3 步）。
