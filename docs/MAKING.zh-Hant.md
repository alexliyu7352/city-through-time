# 做一部你城市的片

[English](MAKING.md) · 繁體中文 · [简体中文](MAKING.zh-Hans.md)

這份教學帶你從零開始，用《一城春秋》的技能做出一部城市影片。做片的是 Claude Code（程式代理），你負責定方向、在瀏覽器裡檢查每一步；細節規則都在 [`SKILL.md`](../SKILL.md)，代理會照它做。

## 1. 先看一部

先在[入口頁](https://cities.go5.si/xianyang/)看咸陽那部，知道成品長什麼樣：白色模型、一個時代一種顏色、連貫的旁白、每條史實都有出處。

## 2. 準備電腦

| 需要 | 用途 |
|---|---|
| [Claude Code](https://claude.com/claude-code) | 做片的代理 |
| Node 20 以上 | 播放器、渲染工具 |
| [uv](https://docs.astral.sh/uv/) | Python 環境（它會自己下載 Python 3.12） |
| ffmpeg、exiftool | 影片合成、清除元數據 |
| Chrome 和一張顯示卡 | 渲染畫面（沒有顯示卡也能跑，但慢很多） |

硬碟：每座城大約 5 GB 工作空間（下載的地圖與建築資料、渲染中的影格和音軌）。如果要在本機生成配樂，模型另外約 6 GB。

時間參考（咸陽，12 分 30 秒的片，2019 年的桌機）：編譯一次約 3 分鐘，整片渲染約 36 分鐘，混音約 2 分鐘。研究和逐段修改花的時間最多，通常要幾天。

## 3. 安裝

```sh
git clone https://github.com/alexliyu7352/city-through-time.git
ln -s "$PWD/city-through-time" ~/.claude/skills/city-through-time
```

第二行讓 Claude Code 認得這個技能。之後在 `city-through-time` 資料夾裡打開 Claude Code。

## 4. 第一次使用

跟代理說：「用一城春秋做〇〇，從〇〇時代開始」。第一次它會先做「第一次使用」這一步：

- 問你這台電腦的資料放在哪裡，寫進 `local/config.json`（不進 git）。建議全部放在專案的 `local/` 下；硬碟不夠時，也可以把大檔放到別顆硬碟。
- 檢查工具裝了沒有，用 `npm ci` 和 `uv sync` 裝好環境。

## 5. 做片的流程

代理會照下面的順序做，每一步都會停下來給你看。要改程式或換做法時，它會先說明原因和做法，你同意才動手；你點名的問題，它只改那幾處，同類的問題它會自己找出來列給你看：

1. **研究**：年代表、每條史實的出處和原文（`FACTS.md`），選出這座城的轉折點。
2. **資料**：劃定範圍（約 20–30 公里見方），抓 OpenStreetMap、建築、地形、衛星影像，先渲染一張白模給你看比例。
3. **歷代城市**：照考古報告和史料生成各時代的城，畫面上標「示意」。
4. **文案與時間軸**：先寫一條連貫的旁白，再讓畫面跟著句子走。
5. **預覽**：`node tools/preview.mjs <城市>` 起本機伺服器，在 Chrome 打開它印出的網址就能播放；做完一段看一段，有問題直接跟代理說。
6. **旁白、配樂與音效**：代理會先問你用哪種方式：自己錄、線上服務（例如 MiniMax）、本機模型（例如 Stable Audio 3）、CC 曲庫，或是程式寫的配樂（不用模型、離線、免費，當作備用）。選定的方式和它的使用條款（能不能公開、能不能商用）會寫進城市的 `VOICE.md`、`MUSIC.md`。音效（光柱落地、焚城、熄燈這些時刻）可以挑，也可以不用；三樣都能在預覽裡聽。
7. **成片**：你在預覽裡點頭後才渲染：`node tools/build.mjs <城市>`。它會跑完所有檢查，交出 `dist/` 裡的影片、雙語字幕、封面和簡介。

## 6. 幾個要守的原則

- **每一條史實都要有出處**，寫在 `FACTS.md`；找不到的寧可不說。
- **示意就標示意、估算就標估算**：歷代城市是示意模型，建築年份是衛星估算。
- **只用可以公開的素材**：CC 授權或公有領域的圖片與實拍，作者和授權寫進 `CREDITS`。
- **AI 生成的要說清楚**：旁白、配樂、想像圖都在畫面和片尾標註。
