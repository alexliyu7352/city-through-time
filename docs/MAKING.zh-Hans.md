# 做一部你城市的片

[English](MAKING.md) · [繁體中文](MAKING.zh-Hant.md) · 简体中文

这份教程带你从零开始，用《一城春秋》的技能做出一部城市视频。做片的是 Claude Code（编程代理），你负责定方向、在浏览器里检查每一步；细节规则都在 [`SKILL.md`](../SKILL.md)，代理会照它做。

## 1. 先看一部

先在[入口页](https://cities.go5.si/xianyang/)看咸阳那部，知道成品长什么样：白色模型、一个时代一种颜色、连贯的旁白、每条史实都有出处。

## 2. 准备电脑

| 需要 | 用途 |
|---|---|
| [Claude Code](https://claude.com/claude-code) | 做片的代理 |
| Node 20 以上 | 播放器、渲染工具 |
| [uv](https://docs.astral.sh/uv/) | Python 环境（它会自己下载 Python 3.12） |
| ffmpeg、exiftool | 视频合成、清除元数据 |
| Chrome 和一张显卡 | 渲染画面（没有显卡也能跑，但慢很多） |

硬盘：每座城大约 5 GB 工作空间（下载的地图与建筑数据、渲染中的帧和音轨）。如果要在本地生成配乐，模型另外约 6 GB。

时间参考（咸阳，12 分 30 秒的片，2019 年的台式机）：编译一次约 3 分钟，整片渲染约 36 分钟，混音约 2 分钟。研究和逐段修改花的时间最多，通常要几天。

## 3. 安装

```sh
git clone https://github.com/alexliyu7352/city-through-time.git
ln -s "$PWD/city-through-time" ~/.claude/skills/city-through-time
```

第二行让 Claude Code 认得这个技能。之后在 `city-through-time` 文件夹里打开 Claude Code。

## 4. 第一次使用

跟代理说：“用一城春秋做〇〇，从〇〇时代开始”。第一次它会先做“第一次使用”这一步：

- 问你这台电脑的数据放在哪里，写进 `local/config.json`（不进 git）。建议全部放在项目的 `local/` 下；硬盘不够时，也可以把大文件放到另一块硬盘。
- 检查工具装了没有，用 `npm ci` 和 `uv sync` 装好环境。

## 5. 做片的流程

代理会照下面的顺序做，每一步都会停下来给你看。要改程序或换做法时，它会先说明原因和做法，你同意才动手；你点名的问题，它只改那几处，同类的问题它会自己找出来列给你看：

1. **研究**：年代表、每条史实的出处和原文（`FACTS.md`），选出这座城的转折点。
2. **数据**：划定范围（约 20–30 公里见方），抓 OpenStreetMap、建筑、地形、卫星影像，先渲染一张白模给你看比例。
3. **历代城市**：照考古报告和史料生成各时代的城，画面上标“示意”。
4. **文案与时间轴**：先写一条连贯的旁白，再让画面跟着句子走。
5. **预览**：`node tools/preview.mjs <城市>` 起本地服务器，在 Chrome 打开它打印出的网址就能播放；做完一段看一段，有问题直接跟代理说。
6. **旁白、配乐与音效**：代理会先问你用哪种方式：自己录、在线服务（例如 MiniMax）、本地模型（例如 Stable Audio 3）、CC 曲库，或是程序写的配乐（不用模型、离线、免费，当作备用）。选定的方式和它的使用条款（能不能公开、能不能商用）会写进城市的 `VOICE.md`、`MUSIC.md`。音效（光柱落地、焚城、熄灯这些时刻）可以挑，也可以不用；三样都能在预览里听。
7. **成片**：你在预览里点头后才渲染：`node tools/build.mjs <城市>`。它会跑完所有检查，交出 `dist/` 里的视频、双语字幕、封面和简介。

## 6. 几个要守的原则

- **每一条史实都要有出处**，写在 `FACTS.md`；找不到的宁可不说。
- **示意就标示意、估算就标估算**：历代城市是示意模型，建筑年份是卫星估算。
- **只用可以公开的素材**：CC 许可或公有领域的图片与实拍，作者和许可写进 `CREDITS`。
- **AI 生成的要说清楚**：旁白、配乐、想象图都在画面和片尾标注。
