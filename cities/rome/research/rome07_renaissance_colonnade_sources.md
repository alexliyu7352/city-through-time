# 1667柱廊：連續覆頂與兩端接合

採用Falda1667原圖R09的兩曲臂、直翼及Borgo街坊關係；另核Met414681的Falda1665–69《Piazza e Portici》原版畫R36。兩張圖都畫了未實現第三臂，因此它們不是逐項完工清冊。東口第三臂排除，Borgo spina保留；曲臂西端接封閉的斜直翼，東端才是獨立終端面。連續檐帶、欄杆及沿曲臂的屋脊不能變成反覆的28m山牆模組。

Alfarano／Bonifacio1590疊圖R03只管舊／新聖彼得同址關係。它早於Bernini工程，不用來證後來柱廊的屋面。現代官方照片R23只核結構存留，不定1667雕像或南臂後改屋高。

補得Marcello Villani《Il Colonnato di piazza S.Pietro》[作者機構原PDF](https://ricerca.unich.it/retrieve/e4233f16-4dae-2860-e053-6605fe0a460a/Il%20Colonnato%20di%20piazza%20S.%20Pietro.%20Pdf.pdf)，R35，306頁。實看PDF42／印刷40圖31、PDF111／印刷109圖73–74、PDF116／印刷114圖81–82、PDF151／印刷149圖119–121。印刷36成品柱含柱基／柱頭12.847m、檐部約3–3.20m；本件採12.847＋3.20。印刷109及Bernini剖面支持雙坡瓦頂；不能用平屋面刪掉原頂。印刷125–126說南臂1734抬屋面，未照現況回填。

整廊使用原生`parts / prism / column / long_hall`。三圓心曲線按圖119各半臂描讀／原生fit_circle，不用完美橢圓。圖的四個內緣尺度點經原生register affine對到Fabbrica196×149m工作尺寸；0.20m殘差、0.80–0.81m留一只反映尺寸化的圖讀控制，並非實地測量精度。絕對錨及轉向採今日方尖碑中心附近與大殿軸，仍列約5m／數度工作容差。檐／欄杆取連續原生prism窄帶；約4m長的低三角屋面段沿同高曲脊接合，端面藏於相鄰段內，不反覆露出山牆。保留這個已判圖分支；8e43c3c已修partial-revolve用地，沒有為工具更新重做已乾淨的窄帶。兩斜直翼另按各自用地落地，不把全廣場放在無據厚台上；古代地坪坡度未復原。

覆廊16.77m、四列來自R06；柱徑1.5m、縱距約4.6m、橫向軸線1.1／5.7／10.3／14.9m、低屋脊起1.5m、欄杆1.56m高和細柱節奏均為有界估配，不稱284柱／88柱墩逐個測繪。模型省略完整基座、古典柱頭、三通道的內部拱頂、簷細部、徽章及全部頂像；不把今日140像在1667一次畫齊。兩東端局部山牆只出現在終端面；西端為相接的封閉翼，不複製一排神殿。

原圖`R09_falda1667_colonnade_source.jpg`、`R36_falda_piazza_met.jpg`、`R35_ovale119.png`及`R35_pdf116.png`均已實看。R35只供研究參照，不把作者PDF／圖版直接放上屏。R36的[Met藏目](https://www.metmuseum.org/art/collection/search/414681)明列公領域，也明列未實現第三臂。
