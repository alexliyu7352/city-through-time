# 1975–2020：當代羅馬資料生長首件

**本件結論：** 既有GHSL／Overture足以開始一段有明確資料界線的城市生長，毋須重造1975整城或新增住宅房型。先採`reset + grow`的建成面估計；不以GHSL-V驅動逐棟「改建增高」。可合併原生欄位見`rome12_modern_native_fragment.yaml`，但正式合併前須處理預測年代外溢及五年節點成批出現，最小證據見`rome12_modern_shared_tool_issue.md`。

本件只交step4資料／形制調查與變化提案；沒有修改正式staging、文字、city.yaml、script.yaml、FACTS、底模或共享程式。1990世界盃保持在第12站生長畫面上一句帶過，不飛球場、不把賽事當擴張原因。

## 年代分組與不能說的事

本機讀取器按輪廓質心所在100m cell首次達1500m²建成面的五年節點，給現代輪廓一個估計年代。1500m²是本專案閾值，不能叫JRC逐棟建造年；「100m」是網格解析度，不是逐棟定位精度保證。JRC原始產品也不是每五年獨立觀測：官方原PDF Table10列1975、1990、2000、2014、2018五個觀測時點，其餘等間隔格網經時空估計生成。

| 模型估計年 | 輪廓數 |
|---|---:|
| 未定年0 | 19,128 |
| 1975或更早 | 105,425 |
| 1980 | 965 |
| 1985 | 978 |
| 1990 | 921 |
| 1995 | 3,463 |
| 2000 | 3,103 |
| 2005 | 2,284 |
| 2010 | 2,293 |
| 2015 | 1,708 |
| 2020 | 572 |
| 2025／2030預測閾值 | 23／3 |

`reset.year=1975`收回的是有較晚估計年的樓，未定年0仍留作現況背景；起點因此必須標為「據GHSL估計／現況輪廓」，不能叫精確1975城市。1975年的105,425也只代表該cell早已達閾值，不證明每棟2026外框在1975已原樣存在。1975以前不分逐棟建造、拆除或歷次改建。

本件沒有加任何普通住宅。既有古羅馬approved types不適用現代城市，故不沿用。普通街廓、宅界、院落、樓層分布全部由當代資料給足跡／估高，不再用推測比例鋪城；沒有把未知住宅類型或缺漏地塊填成格子院宅。原始height優先、其次樓層×3.2m、再回退9m的規則沿用S75；96筆輸出高度為0的近景限制仍在。

## 可直接採用與主代理排畫面的界線

1. 以`rome12_modern_native_fragment.yaml`的原生`reset/grow.mono/grow.warm/bands`欄位為起點，保留既有古城／河流／競技場尺度錨，生長採現代足跡＋GHSL估計。
2. 不啟用`change:ghsl`、taller計數或逐棟先矮後高。若須另作2018固定高度參照，必須明說其靜態來源，不能叫歷史增高觀測。
3. T02只依r12_05–06在全城仍生長時短標球場，不新增tour stop。`tour`及`year:`的自動停年行為見issue；時間、鏡頭與具體標記顯示窗由主代理step5處理。
4. 生長歷史截止2020與故事抵達2026分開。依d6cc2b2，26筆推估層對應現況輪廓的顯示年由native統一估在2020–2025，不能稱逐棟實測竣工；19,128未定年只是現況背景，註記不能漏。
5. 保留實際無屋面空間，不將公園、球場內場、河流、道路、廣場、農地一律填樓。全城資料底模已具水路；本件沒有另描公園邊界、任意種樹或把歷史建成表面積等同整片地表覆蓋。

本片段YAML已可解析且grow.bands數與既有6 bands相符；欄位已逐項對照原生compile／shader。未跑正式compile、rangecheck、eraview或modelview，因本件沒有生成或修改幾何。沒有圖像樣張，也不聲稱模型／鏡頭已驗收。首件完成在可審來源調查及變化提案；共享issue需由主線解決後，主代理再安排一次獨立生長預覽與範圍檢查。
